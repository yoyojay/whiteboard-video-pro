# 白板视频 Pro 1.0

手绘白板风「边画边讲」讲解视频工作台。**写文案就能出片，不用剪辑软件。**

旁白配音 → 逐笔动画 → 烧录字幕 → 品牌水印（可选）→ 片尾卡（可选）→ 横竖两张封面，全部本地跑完。

## 三步出片

```bash
npm install
./安装.sh                      # 一次性设置：项目目录 / 品牌水印 / 画幅 / 配音

./bin/wb new "第一期标题"      # 建期，写文案
./bin/wb stills "第一期标题"   # 出静帧，逐张看排版
./bin/wb shoot "第一期标题"    # 配音 → 渲染 → 混音 → 封面
```

成片在 `build/<日期 标题>/outputs/final.mp4`，封面和字幕在期目录里。

---

## 成片是干净的

1.0 交付版**默认不打水印、不要片尾卡**，出片里没有本产品的任何字样。

想打自己的品牌，编辑 `我的设置.json`：

```json
{
  "brand": {
    "name": "你自己的品牌",
    "watermark": { "enabled": true, "text": "你自己的品牌" },
    "endCard": { "enabled": true, "slogan": "每天一讲", "contact": "你的联系方式" }
  }
}
```

填什么打什么，位置、字号、透明度、四个角任选。
定制引导只出现在安装过程和终端输出里，不进视频。

## 能改什么

编辑 `我的设置.json` 一处，其余一概不用碰：

| 类别 | 具体 |
|---|---|
| 水印与片尾卡 | 开关、文字、位置、大小、透明度、Logo、slogan、联系方式、时长 |
| 内容 | 每期 `scenes.js` 文案、贴纸素材 |
| 声音 | 音色 ID、语速、语气、音高、角色表、换人换气口 |
| 字幕 | 字号、位置、最大字数、竖版专属参数 |
| 画面与声音 | 画幅 9:16 / 16:9、配乐文件与音量、封面画幅与系列标签 |
| 路径 | 期目录放哪儿、出帧并发数、帧率 |

**唯一不可改的是风格**：配色、字体、书写节奏。
原因写在 [`02`](02-可改项与不可改项.md) 里，想放开走 [`03`](03-自定义风格与升级通道.md)。

## 限制写入机制

`guard.js` 守两条线，实测过的行为：

```
node guard.js
  完整性锁：通过（20 个文件）
  我的设置：已配置
  成片水印：未配置 → 默认不打，成片干净
  片尾品牌卡：未配置 → 默认关
```

| 你做的事 | 结果 |
|---|---|
| 改 `我的设置.json` 的水印 / 文案 / 音色 / 画幅 | ✅ 立刻生效 |
| 改期目录 `scenes.js` 的文案与 `assets/` 贴纸 | ✅ 随便改，工具不拦 |
| 改配色 / 字体 / 书写节奏 | ❌ 被忽略 + 打印原因 |
| 改 `lib/*.js` 或 `config.json` | ❌ `wb shoot` 直接 exit 1，出不了片 |

被拦了怎么办：把 1.0 包重新解压覆盖，期目录（`scenes.js` 和 `assets/`）不受影响。
要走定制路线见 [`03`](03-自定义风格与升级通道.md)。

## 可持续更新

改 `version.json` 的版本号，跑一条命令就出新包：

```bash
python3 构建/打包.py                 # 或 python3 构建/打包.py --ver=1.0.1
```

自动做四件事：重建核心版 → 生成交付版（注入守卫 + 算 SHA256）→
锁文件清单 → 打 zip 并出校验值。

用户升级时：备份期目录 → 覆盖 → 重跑 `./安装.sh` → `我的设置.json` 直接沿用。

## 已知限制

- **依赖要自己装**：包里不带 `node_modules`，跑 `npm install` 一次即可（约 2 分钟）
- **配乐不自带**：放一首无版权音乐到 `assets/bgm.mp3`，没有就出无配乐成片
- **语音要钱**：豆包 TTS 按量计费，新账号有免费额度
- **贴纸生成**：靠本地 codex CLI 出图，装不了就用期目录 `assets/` 里的贴纸，
  或用 `./bin/wb keyout 期 图片路径` 把自己的图抠成透明底贴纸
- **风格不可自定义**：这是授权范围，放开要买定制版
