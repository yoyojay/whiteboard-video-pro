## 三步出片

```bash
npm install
./安装.sh                      # 一次性设置：水印、画幅、音色

./bin/wb new "第一期标题"      # 建期，写文案
./bin/wb stills "第一期标题"   # 出静帧，逐张看排版
./bin/wb shoot "第一期标题"    # 配音 → 渲染 → 混音 → 封面
```

成片在 `build/<日期 标题>/outputs/final.mp4`，封面和字幕在期目录里。

## 这一版解决了什么问题

白板视频的能力都一样：写文案、配音、逐笔动画、烧字幕、出片。差别在**拿到手之后顺不顺**。

| 常见痛点 | 这里的处理 |
|---|---|
| 配一套环境要翻半天文档，音色 ID 填错就报错 | `./安装.sh` 一次问完（项目目录 / 水印 / logo / 联系方式 / 画幅 / 凭证 / 音色），生成配置 |
| 想改个水印，一不小心把版式改坏了，出片才发现 | 只开放「水印 / 内容 / 声音 / 字幕 / 配乐」这五类改动，其余写进去会被拦下并告诉你为什么 |
| 团队里每个人装一遍，每次版本都不一样 | `version.json` + 打包脚本，一条命令出同构的包，配置跨版本沿用 |
| 语音模型要自己摸索 | 安装过程直接带你走豆包语音克隆，附完整开通与报错对照 |

核心代码没有改动，外面加的只有配置守卫、安装向导和文档这三件事。

## 限制写入机制

1.0 靠 `guard.js` 守三条线，实测过的行为：

```
node guard.js
  完整性锁：通过（20 个文件）
  我的设置：已配置
  广告植入：强制（水印 + 片尾 CTA）
```

| 你做的事 | 结果 |
|---|---|
| 改 `我的设置.json` 的水印文字 | ✅ 立刻生效 |
| 改期目录 `scenes.js` 的文案 | ✅ 正常出片 |
| 改配色 / 字体 / 版式坐标 | ❌ 被守卫忽略 + 打印原因 |
| 改 `lib/*.js` 或 `config.json` | ❌ `wb shoot` 直接 exit 1，出不了片 |
| 手动绕过守卫 | 提示重新解压覆盖，每步都记 `guard.log` |

被拦了怎么办：把 1.0 包重新解压覆盖，期目录（`scenes.js` 和 `assets/`）不会受影响。
要走定制路线见 [`03`](03-自定义风格与升级通道.md)。

## 广告植入

1.0 交付版强制带，这一版不允许关：

- **右上角水印**：你的品牌名（默认 YoJo AIcademy，可换成你自己的）
- **片尾卡**：在你自己的 hooks 后面自动追加两条 ——
  「更多 AI 定制工具 → yojo.yingmind.com」「需要专属定制找小悠」
- **定制入口**：更多应用定制、批量生产、团队多人协作 → yojo.yingmind.com 找小悠

水印可改成你自己的品牌，片尾两条引导文案在 `我的设置.json` 的 `brand.endCard.hooks`
里没法删（守卫会补回来）—— 想完全去掉，走定制版。

## 可持续更新

改 `version.json` 的版本号，跑一条命令就出新包：

```bash
python3 构建/打包.py                 # 或 python3 构建/打包.py --ver=1.0.1
```

自动做四件事：重建核心版 → 生成交付版（注入守卫 + 锁 config + 广告）→
算 20 个风格锁文件的 SHA256 → 打 zip 并出校验值。

用户升级时：备份期目录 → 覆盖 → 重跑 `./安装.sh` → `我的设置.json` 直接沿用。
`我的设置.json` 跨版本兼容，不用重填。

## 已知限制

- **依赖要自己装**：包里不带 `node_modules`，跑 `npm install` 一次即可（约 2 分钟）
- **配乐不自带**：放一首无版权音乐到 `assets/bgm.mp3`，没有就出无配乐成片
- **语音要钱**：豆包 TTS 按量计费，新账号有免费额度
- **贴纸生成**：靠本地 codex CLI 出图，装不了就用期目录 `assets/` 里的贴纸，
  或用 `./bin/wb keyout 期 图片路径` 把自己的图抠成贴纸
